# Cradle CSS agent instructions

Private CSS library extracted from Cradle. Read README.md before changing components.

- Keep the quiet Cradle style, readable 16px base, restrained accents and subtle borders.
- Keep the core framework-free: no required JavaScript, build tools, remote fonts or CDN dependencies.
- Use cr- component classes and --cr- tokens. Keep native element rules scoped inside .cradle.
- Keep palettes and CDN font loading optional; Inter is the default family with system fallbacks. Load Inter and JetBrains Mono from Google Fonts CDN; do not bundle or self-host font files.
- Prefer tokens and existing components to duplicate rules or new variants.
- Update the gallery and README when components change. Record breaking changes and bump the documented version when appropriate.
- Default sizes target a laptop screen (~1440px) or a 24" monitor (1920px), not narrower displays. Do not shrink default layout widths for smaller screens; mobile is handled by responsive rules.
- Verify desktop/mobile, light/dark/auto, keyboard focus, dialog behavior, form feedback and overflow. Use fictional content only.
- Bound external commands with explicit timeouts and stop temporary servers.
- Do not commit, tag or push without explicit user approval in the current turn. After file changes, remind the user to commit and push. Every authorized push to main must deploy the CSS gallery to Bob; the user gave standing deployment authorization on 2026-10-13. Verify the deployed commit, assets, health and sign-in before reporting success.
- Keep secrets and machine-local files out of Git.

## Design references

- 2026-10-13 user preference: remember [Dreeve](https://github.com/dreeveapp/dreeve) as a design reference for Cradle CSS and consider useful patterns during future component work. It is the sports/fitness dashboard formerly called Statistics for Strava, not a design vendor. Research inspected upstream revision `50ac3fb8b6653b69461d713b9228fcbae62be817`. No evidence of earlier adoption was found in this repository's files or commit messages.
- Source similarities: `public/css/tailwind.css` uses Inter, gray borders and a soft accent surface; `public/css/layout/sidebar.css` uses compact navigation with accent selection and count badges. Cradle already has corresponding typography, surfaces, navigation, cards, badges, metrics and tabs; reuse those components rather than duplicate them.
- Best future candidates, in priority order: (1) optional sticky table headers and trailing action columns from `public/css/components/data-table.css`, useful with Cradle's existing overflow wrapper and sorting; (2) semantic breadcrumbs with a current-page marker and long-label handling from `templates/html/navigation/breadcrumbs.html.twig`; (3) determinate progress with separate readable value/target labels, inspired by `templates/html/dashboard/widget/widget--training-goals.html.twig`, plus visible saving/saved/error feedback inspired by `public/css/layout/dashboard-layout.css`. Also consider mixed-width dashboard cards (third/half/two-thirds/full width, stacking responsively) only when a consumer needs them.
- Adapt patterns independently using native HTML, `cr-` classes and `--cr-` tokens; retain Cradle's 16px base and desktop width defaults. Dreeve uses Tailwind/Flowbite and is AGPL-3.0; keep those dependencies out of the core and review upstream licensing before any direct code or asset reuse. This research added no runtime components and does not authorize a redesign. When implementing a candidate, update README/gallery and perform the usual accessibility, theme and responsive checks.
